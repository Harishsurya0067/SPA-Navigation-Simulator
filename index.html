💡 How This SPA Simulation Works

HTML5 History API
1
Intercept Clicks: Links have data-link. When clicked, e.preventDefault() cancels the page reload.
2
Update URL: history.pushState(null, null, path) alters the browser address without sending a server request.
3
Render View: JavaScript router matches the route and injects the corresponding HTML template into <main id="app">.
4
Back/Forward: The window.onpopstate listener automatically detects browser navigation and renders the previous view.
